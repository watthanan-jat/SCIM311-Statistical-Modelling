# SCIM311 course website

This repository contains the public SCIM311 Statistical Modelling course website.

- `index.html`: course overview, assessment, and schedule
- `chapter01.html`: Chapter 1 teaching material

The course material source repository is [WJ-Mim/SCIM311-Statistical-Modelling](https://github.com/WJ-Mim/SCIM311-Statistical-Modelling).

GitHub Pages should publish this repository from the `main` branch at the repository root.
